# Issue #368 docs/impl/ir missing-section 本文補完

## Summary

Issue #368。Issue #365（PR #366）で ir 文書の front matter を
impl-doc schema 準拠に正規化した結果、schema 検証を通過した
文書に対して本文セクション検査が新たに走り、`missing-section`
error が 60 文書・finding 計 319 件残っていた。本タスクで当該
60 文書の本文を補完し、必須 `##` セクション 7 件
（Summary / Context / Implementation / Related Experiments /
Validation / Risks / Follow-ups）を全件に揃え、audit の
`missing-section` を 0 件にした。front matter とファイル名は
全件不変。

  の Follow-ups が「旧形式 IR 文書の本文 section 整備
  （missing-section）を別タスク化」と記録していたもの。
- 補完の実態: 既存本文が正規名以外の見出し
  （`## 実装内容`・`## 検証`・`## 残件`・`## Verification`・
  `## Remaining` 等）にある文書は内容を保持して改題・再配置し、
  セクション自体が無い文書は front matter relations が指す
  上流文書（spec/design/plan/task/test-spec）を参照して事実を
  確認したうえで記述した。

## Implementation

### Changes

- `docs/impl/ir/` の missing-section 保持 60 文書の本文を補完。
  内訳は 3 パターン:
  - 非正規見出しの改題・再配置（例: `## Verification` →
    `## Validation`、`## 残件` → `## Follow-ups`、
    `## 実装内容` → `## Implementation`）。内容は verbatim または
    `###` 小見出しへの demote で保持。
  - 欠落セクションの新規記述（Summary / Context / Risks /
    Follow-ups / Related Experiments）。front matter の
    `implements`/`depends-on`/`related`/`defers` と上流文書を
    根拠に文書固有の事実で記述。
  - Related Experiments は `metadata.experiments` と
    `docs/impl/exp/` の実在ログを確認し、実験未使用の文書は
    その旨を事実として記述（存在しないログへの参照は作らない）。
- doc chain 5 文書と本 IR を新規作成。
- `doc_maintenance.js index apply` で specs/designs/plans/tasks/
  test-specs/impl-ir の管理 index を再生成（新規文書の行追加）。

### Decisions During Implementation

- 本文補完は 11 の並列作業単位（prefix 別バッチ）に分割し、
  各単位が担当文書の front matter relations と上流文書を参照して
  記述した。監査・検証は親側で一括実施。
- 「定型文で埋めない」ためのガードとして、Related Experiments は
  `metadata.experiments` が空かつ `docs/impl/exp/` に関連ログが
  無いことを確認した文書のみ「なし」と記述し、gw-06〜10・sv48
  のように front matter に実験記述がある文書はその内容を転記した。
- 既存の非正規 `##` セクション（`## Decisions`、`## Notes`、
  日付付き追補等）は audit が要求しないため削除せず保持した。

## Risks

- 大量文書の並列補完で個別文書の事実誤認・内容欠落が混入する
  リスク → review-protocol による独立レビュー（協調・敵対の
  2 系統）で Issue Candidate を検証し、CONFIRMED の指摘のみ
  修正した。
- 「形だけの補完」（空見出し・定型文）になるリスク → 受入条件の
  「具体的本文」要求に対し、空セクション・TODO マーカーの
  機械検査（60 文書・問題 0 件）とレビューで担保した。
