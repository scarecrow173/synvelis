synvelis#12 の受入条件 AC-01〜69 と実装 Owner Issue・既存 fixture・
OS Gate の対応台帳。spec `docs/specs/recording-take-comping.md`・
design `docs/designs/recording-take-comping-design.md`・test-spec

状態語彙（POLICIES.md）: Requirement=`Required`/`Deferred`/
`NotApplicable`、実行結果=`Pass`/`Fail`/`NotRun`/`Unsupported`。
本台帳は **実行結果**を分類する。`Pass (headless)` は headless/
unit 契約の実証であり、製品 GUI・実機・実 Device・実 Plugin Pass
ではない。Fake/Headless/Offscreen の成功を実機 Pass と換算しない。

実装 Owner: **#115 RCD-01**（実 Device Capture/同 Clock/Raw Fidelity）・
**#116 RCD-02**（Writer/Journal/Recovery/Asset Manifest）・
**#117 RCD-03**（Monitor/Punch/Latency）・**#118 RCD-04**
（Comp/MIDI Phrase/Recovery E2E/Stable ID）。製品 Gate=#114、
CB 境界=#278/#279/#288、Ruviform 拡張=ruviform#187/#188/#251/#253/#294。

## サマリ

- `Pass (headless)`: 既存 headless/unit テストが契約を実証。
- `Partial`: 一部経路・一部状態のみ実証（literal 件数・実画面経路・
  実 plugin 等の残部は後続 Gate）。
- `NotRun`: 設計契約はあるが本 slice/既存 fixture で未検証。
- `Deferred`: GUI/実機/実 Device/実 Plugin の後続 Gate（#114・EXT-L3・
  ruviform capability Issues）。
- `Unsupported`: capability 非対応を明示。
