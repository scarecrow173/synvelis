## 4. doc-driven-dev-graph router の状態（外部 blocker）

`node .agents/skills/doc-driven-dev-graph/scripts/route_graph.js --focus project-model --json` は
`current: "probe"`・`status: "blocked"`・`edgeId: null` を返す。blockers は
`artifact-graph` + 多数の既存 `broken-relation`（rcd/tim/vcs/automation/pc/sf
等の無関係文書の deferred relation が docs パスとして解決不能）。**本 task
の新規文書起因の finding ではなく repo 全体の baseline 問題**であり、編集範囲外の
ため修復しない。新規文書の relation は doc-status lint / audit で個別に
整合を確認する（verification 記録 V 系参照）。
